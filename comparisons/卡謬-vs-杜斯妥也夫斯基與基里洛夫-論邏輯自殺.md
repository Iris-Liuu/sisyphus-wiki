# 卡謬 vs 杜斯妥也夫斯基與基里洛夫：論邏輯自殺

> **初學者直觀對照**：
> 如果世上沒有上帝，人該怎麼辦？
> * **基里洛夫（杜斯妥也夫斯基小說人物）**說：「如果上帝不存在，我就是自己的神！為了證明我的絕對自由與無所畏懼，我必須親手開槍打死自己！」（**邏輯自殺**）
> * **卡謬**說：「如果上帝不存在，你更應該好好活著！生命的自由不是用一顆子彈來證明的，而是在日復一日推動巨石的奮鬥中活出來的！」（**荒謬的反抗**）

---

## 核心問題意識

在《薛西弗斯的神話》第三部「荒謬的創作」中，卡謬深情而深刻地剖析了俄國大文豪**杜斯妥也夫斯基（Fyodor Dostoevsky）**的小說《群魔》（*Demons / The Possessed*）。

小說中有一個極其震撼人心的角色——**工程師基里洛夫（Kirillov）**。基里洛夫不是因為失戀、破產或痛苦而想死，他是出於**純粹的哲學邏輯**決定自殺。這引發了卡謬對「邏輯自殺」的極限沉思。

---

## 基里洛夫的「人神」邏輯

基里洛夫的腦袋裡有一套無懈可擊的恐怖推理：
1. **前提一**：人活著最大的恐懼，就是對死亡的恐懼，以及為了逃避恐懼而發明出來的上帝。
2. **前提二**：如果上帝存在，一切都是上帝的意志，人只是木偶；**如果上帝不存在，那麼人就是自己的神（人神，Man-God）**。
3. **推論**：既然我是神，我就必須展示我的「絕對自主權（Self-will）」。普通人自殺都是出於恐懼或痛苦，唯有**在毫無動機、毫無恐懼的情況下主動結束生命**，才能證明自己徹底超越了造物主與死亡。
4. **最後遺言**：基里洛夫扣下板機前高喊：「**一切皆好！（All is well!）**」

| 比較維度 | 基里洛夫（小說人物） | 卡謬的荒謬人（薛西弗斯） |
| :--- | :--- | :--- |
| **面臨的前提** | 上帝不存在，世界毫無神聖目的 | 上帝不存在，世界毫無神聖目的 |
| **對自由的證明** | 透過開槍自殺（[[肉體自殺]] 的極致版：邏輯自殺） | 透過拒絕自殺，清醒而熱烈地活著（[[反抗]]） |
| **對神聖性的追求** | 想透過死亡讓自己「成為神」 | 放棄成神的幻想，安心並驕傲地「做一個凡人」 |
| **生命的終局** | 死亡成為一場終極的形上學示範 | 活著成為對冷酷命運最頑強的日常蔑視 |

## 卡謬對杜斯妥也夫斯基的評價：小說家的荒謬與妥協

卡謬對杜斯妥也夫斯基有著極為複雜的情感：
1. **無與倫比的藝術家**：
   * 卡謬讚嘆杜斯妥也夫斯基是最懂荒謬的作家。《群魔》與《卡拉馬助夫兄弟們》把人類理智的撕裂、惡的無解以及沒有上帝之後的道德困境描繪得淋漓盡致。小說正是展現荒謬的最佳容器，因為小說只呈現具體肉體與痛苦，不做廉價的解答。
2. **遺憾的後退（杜氏本人的跳躍）**：
   * 然而卡謬也遺憾地指出，杜斯妥也夫斯基在晚年自己的真實生活中，依然退回了俄羅斯東正教的懷抱，尋求靈魂不朽。
   * 他創造了最偉大的荒謬反抗者（如基里洛夫、伊凡·卡拉馬助夫），但作者本人最終依然承受不了這份孤獨，完成了他自己的[[哲學性自殺]]。
